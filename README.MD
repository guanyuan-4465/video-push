# 视频自动发布工具

一个用于自动发布视频的GUI工具。

## 功能特性

- 视频批量上传
- 定时发布
- 自动填写标题和标签
- 图形界面操作

## 安装

1. 创建虚拟环境：
python
python -m venv vritual-envrionment


2. 激活虚拟环境：
bash
Windows
.\vritual-envrionment\Scripts\activate
Linux/Mac
source vritual-envrionment/bin/activate

3. 安装依赖：
bash
pip install -r requirements.txt

## 使用

运行以下命令启动程序：
bash
python run.py
